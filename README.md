# InnoMindGames
Telegram-бот для игры в «Что? Где? Когда?».
Загружает вопросы из .docx-файлов, задаёт их по одному с таймером на ответ,
принимает ответы реплаем, ведёт счёт.

## Возможности
* Игра в групповом чате: вопрос → 60 секунд на ответ → правильный ответ
* Ответ принимается реплаем на сообщение с вопросом
* Если ответ не совпал с эталоном — суд: «считаем правильным?» (Да / Нет)
* Счёт правильных и неправильных ответов, итоговая сводка в конце турнира
* Турниры загружаются из .docx и хранятся в SQLite
* Повторная загрузка того же файла обновляет турнир, а не дублирует

## Стек
Python 3.12, aiogram 3, SQLite, uv.

## Запуск

```powershell
uv run python bot.py
```
## Загрузка турниров
Положи .docx-файлы в data/source/. Выполни из корня проекта:

```powershell
uv run python -m scripts.load_questions
```
Скрипт распарсит все файлы в папке и загрузит турниры в data/questions.db.

Если передать аргумент — обработает конкретный файл или папку:
```powershell
uv run python -m scripts.load_questions "data/source/Турнир.docx"
uv run python -m scripts.load_questions data/source/new_batch/
```
Если турнир с таким именем уже есть в БД — он будет обновлён (id турнира сохраняется, туры и вопросы перезаписываются).

## Как играть
Добавь бота в групповой чат.
/tournaments — выбрать турнир кнопкой.
Бот присылает вопрос — ответь реплаем на это сообщение.
Если ответ не совпал, бот спросит: «считаем правильным?» — нажми Да / Нет.
/stop — прервать игру.
После последнего вопроса бот пришлёт счёт.

## Команды:

/start — приветствие

/tournaments — список турниров кнопками

/play \<id\> — запустить турнир по id (в обход меню)

/stop — остановить игру в чате


## Формат docx
Парсер ожидает стандартный формат турниров ЧГК:

```text
<Название турнира>
Редакторы: Иван Иванов, Пётр Петров

Тур 1

Вопрос 1
<Текст вопроса.>
Ответ: <правильный ответ>.
Зачёт: <альтернативные ответы через ;>
Комментарий: <произвольный текст.>
Источники: <ссылка или описание.>
Автор: <Имя Фамилия>

Вопрос 2
<Текст вопроса.>
Ответ: <правильный ответ>.
Зачёт: <альтернативные ответы через ;>
Комментарий: <произвольный текст.>
Источники: <ссылка или описание.>
Автор: <Имя Фамилия>

...

Тур 2

Вопрос 13
<Текст вопроса.>
Ответ: <правильный ответ>.
Зачёт: <альтернативные ответы через ;>
Комментарий: <произвольный текст.>
Источники: <ссылка или описание.>
Автор: <Имя Фамилия>

...
```
Текст вопроса может занимать несколько абзацев. Поле "ответ" обязательно, остальные могут не присутствовать.



## Структура проекта
```text
bot.py              — точка входа
config.py           — читает .env

db/                 — SQLite
parser/             — docx → структура турнира
game/               — логика раунда
handlers/           — обработчики команд и ответов
scripts/            — CLI: load_questions

data/source/        — исходные .docx с вопросами
data/questions.db   — база 
```
